## 搬瓦工官网到底是哪个？为什么国内打不开

搬瓦工的英文品牌名是 BandwagonHost，运营主体是 IT7 Networks Inc.，2012 年成立，总部在加拿大，卖的是基于 KVM 架构的自管理 VPS。官网主域名 bandwagonhost.com 在国内长期无法直连，这不是临时故障，也和商家经营状况无关，属于网络访问层面的限制。

官方的解决方案是镜像站。目前国内能直接打开、数据与主站实时互通的官方镜像里，bwh81.net 最稳定，也是客服目前主动告知用户的地址（该域名 2021 年 3 月 30 日启用）；bwh89.net 基本可用，bwh88.net 和 bwh8.net 偶尔可用，bwh1.net 已经不稳定。遇到 bwh81.net 也打不开的情况，可以按这个顺序往下试，或者换一下网络环境、清掉浏览器缓存再试。

有一个风险必须单独说：网上有大量仿冒搬瓦工的假网站，专门钓鱼骗账号密码，中文社区里有用户因为搜到山寨站泄露过账号信息。辨别方法很直接——只认上面列出的这几个官方域名，域名对不上就不要输入账号密码，更不要付款。搜索结果里那些中文“搬瓦工官网”站点（各种中文网、维基站）都是第三方整理站，查教程可以，注册购买只走官方主站或官方镜像。

## 购买流程与三个容易翻车的点

流程本身不难：进入官网或镜像站 → 右上角 Register 注册（真实邮箱，账单国籍如实填写，会影响税率显示）→ 选套餐加购物车 → 付款支持支付宝、PayPal、信用卡，支付宝按实时汇率扣人民币 → 几分钟内收到含 VPS IP 和 KiwiVM 后台链接的邮件 → 后台设 root 密码后 SSH 连接。

容易翻车的三处：

1. **下单被风控拦截**。提示“欺诈订单被拒绝”通常是 IP 和账单信息不匹配——开着代理、IP 显示欧美，账单地址却填中国。关掉代理，用国内 IP 直接走镜像站下单即可。
2. **优惠码白找**。前面说过，常规循环码已取消，第三方流传的码以结账页验证为准。
3. **当成托管服务买**。同上，自管理 VPS，不懂 Linux 的话先想清楚运维成本。
